# Cheatsheet — Part 4: Incompressibility and Typicality

*Exam recap: definitions, formulas and key results only, covering the chapter Incompressibility and Typicality (the three-step exercise and Theorem 4.1) up to (but excluding) Computable Approximations of Real Numbers. Full explanations live in the [main notes]({{ '/subpages/books/algorithmic_randomness_computable_analysis/' | relative_url }}#incompressibility-and-typicality). Prerequisites in [Part 1]({{ '/subpages/books/algorithmic_randomness_computable_analysis/cheatsheet-part1-plain-complexity/' | relative_url }}), [Part 2]({{ '/subpages/books/algorithmic_randomness_computable_analysis/cheatsheet-part2-prefix-free-complexity/' | relative_url }}) and [Part 3]({{ '/subpages/books/algorithmic_randomness_computable_analysis/cheatsheet-part3-information-content-measures/' | relative_url }}).*

## Where we are

Part 1 opened with three intuitions of nonrandomness. Two of them now have precise definitions, and this chapter proves that they single out the **same** sequences.

| Intuition (Part 1) | Formal notion | Definition | Status |
| :-- | :-- | :-- | :-- |
| **Untypicality** (§1.3) | Martin-Löf random | Def. 1.5: no ML test $(M\_i)$ with $X \in \bigcap\_i M\_i$ | this chapter: $\iff$ 1-random |
| **Compressibility** (§1.1) | 1-random | Def. 3.8: $\exists c\ \forall n: K(X \upharpoonright n) \ge n - c$ | this chapter: $\iff$ ML-random |
| **Predictability** (§1.2) | no c.e. martingale succeeds | later (Martingales chapter) | joins the equivalence later |

**The two negations, which is what the proofs actually use:**

$$X \text{ is ML-nonrandom} \iff \exists \text{ ML test } (M_i):\ X \in M_i \text{ for every } i,$$

$$X \text{ is 1-nonrandom} \iff \forall i\ \exists n:\ K(X \upharpoonright n) \le n - i \iff K(X \upharpoonright n) - n \text{ is unbounded below}.$$

(Shifting $i$ by one trades "$<$" for "$\le$": $K$ and $n$ are integers.)

**The dictionary behind both directions:** *$i$ bits of compression $\longleftrightarrow$ a factor $2^{-i}$ of measure.* A short program for a word makes that word's cylinder cheap in program-mass; a layer of small measure makes its words cheap to describe.

## The compression test

<div class="math-callout math-callout--question" markdown="1">
  <p class="math-callout__title"><span class="math-callout__label">Exercise</span><span class="math-callout__name">(Typicality implies incompressibility)</span></p>

1. For a prefix-free machine $M$ and $i \in \mathbb{N}$ let $L\_i^M := \lbrace \sigma : C\_M(\sigma) \le l(\sigma) - i\rbrace$. Then

   $$\sum_{\sigma \in L_i^M} 2^{-l(\sigma)} \;\le\; 2^{-i}\, \lambda(\mathrm{dom}(M)) \;\le\; 2^{-i}.$$

2. The open sets $\widetilde L\_i := \lbrace X : \exists n\ K(X \upharpoonright n) \le n - i\rbrace$ form a **Martin-Löf test**.
3. Every Martin-Löf random $A$ has a constant $c$ with $K(A \upharpoonright n) \ge n - c$ for all $n$.

</div>

### Step 1 — compressed words are light

* Pick for each $\sigma \in L\_i^M$ a shortest code $\tau\_\sigma$, so $l(\tau\_\sigma) = C\_M(\sigma) \le l(\sigma) - i$, i.e.

$$2^{-l(\sigma)} \;\le\; 2^{-i}\, 2^{-l(\tau_\sigma)}.$$

* $\sigma \mapsto \tau\_\sigma$ is **injective** (one code outputs one word), so summing and enlarging to all of $\mathrm{dom}(M)$:

$$\sum_{\sigma \in L_i^M} 2^{-l(\sigma)} \;\le\; 2^{-i} \sum_{\sigma \in L_i^M} 2^{-l(\tau_\sigma)} \;\le\; 2^{-i} \sum_{\tau \in \mathrm{dom}(M)} 2^{-l(\tau)} \;=\; 2^{-i}\,\lambda(\mathrm{dom}(M)) \;\le\; 2^{-i},$$

  the last two steps being disjoint cylinders and **Kraft** (Prop. 2.25). *Each bit of compression halves the measure the compressed words can occupy.*
* ⚠️ The notes state step 1 as $\lambda(L\_i) \le \lambda(\mathrm{dom}(M))$ — the factor $2^{-i}$ is missing, and it is exactly what step 2 needs. Proof I in the notes also drops the lengths ($2^{-\tau\_\sigma}$ for $2^{-l(\tau\_\sigma)}$), reverses its middle inequality, prints $2^{i}$ for $2^{-i}$ and $\sigma\_{\sigma \in L\_i}$ for $\sum\_{\sigma \in L\_i}$, and stops before the final Kraft step. The displayed chain above is the intended one.

### Step 2 — the layers form a test

Write $L\_i := L\_i^{\widetilde U} = \lbrace \sigma : K(\sigma) \le l(\sigma) - i\rbrace$. Then $\widetilde L\_i$ is the open set generated by $L\_i$:

$$\widetilde L_i = \bigcup_{\sigma \in L_i} [\![\sigma]\!].$$

* **Open:** union of cylinders.
* **Uniformly c.e.:** $K$ is upper-semicomputable (Prop. 2.23), so enumerate all certificates $(\sigma, k)$ with $K(\sigma) \le k$ and keep those with $k \le l(\sigma) - i$. You never need to know $K(\sigma)$ exactly — a short program *witnesses* membership.
* **Measure:** step 1 with $M = \widetilde U$ and the union bound,

$$\lambda(\widetilde L_i) \;\le\; \sum_{\sigma \in L_i} 2^{-l(\sigma)} \;\le\; 2^{-i}\,\lambda(\mathrm{dom}(\widetilde U)) \;\le\; 2^{-i}.$$

* **Nested:** $\widetilde L\_{i+1} \subseteq \widetilde L\_i$ (compressing by $i+1$ bits compresses by $i$).
* **The one place prefix-freeness enters** is $\lambda(\mathrm{dom}(\widetilde U)) \le 1$. For plain $C$ the same layers $\lbrace X : \exists n\ C(X \upharpoonright n) \le n - i\rbrace$ have **measure $1$** for every $i$ (Thm. 1.3: *every* sequence dips below $n - c$ infinitely often) — there is no test, and no randomness notion.
* Proof II in the notes uses "$<$" and gets $\lambda \le 2^{-(i+1)}$; with "$\le$" as in the statement and in Thm. 4.1 the bound becomes $2^{-i}$. Either is a test.

### Step 3 — random sequences escape

$A$ ML-random $\Rightarrow$ $A \notin \widetilde L\_c$ for some $c$ (by nestedness, for all larger $c$ too) $\Rightarrow$ $K(A \upharpoonright n) > n - c$ for **all** $n$. That is Def. 3.8: $A$ is 1-random.

### Reading the layers

* **Level sets of the deficiency.** With $d(X) := \sup\_n\,(n - K(X \upharpoonright n))$,

$$\widetilde L_i = \lbrace X : d(X) \ge i\rbrace, \qquad \bigcap_i \widetilde L_i = \lbrace X : d(X) = \infty\rbrace = \lbrace X : X \text{ is 1-nonrandom}\rbrace.$$

  1-random $\iff$ finite deficiency; Def. 3.8 holds with a constant $c$ iff $c \ge d(X)$, so the least admissible constant is $\max(d(X), 0)$.
* **Almost every sequence is 1-random.** The 1-nonrandom sequences form $\bigcap\_i \widetilde L\_i$, of measure $\le 2^{-i}$ for every $i$, hence a **null set**. This gives existence of 1-random sequences for free — more directly than the König-lemma argument in Part 3, and it needs only step 2.

## Theorem 4.1

<div class="math-callout math-callout--theorem" markdown="1">
  <p class="math-callout__title"><span class="math-callout__label">Theorem</span><span class="math-callout__name">(4.1 — Incompressibility equals typicality)</span></p>

$$X \text{ is 1-random} \iff X \text{ is Martin-Löf random}.$$

</div>

Both directions are proved **contrapositively**, each by building the other side's object out of the given one.

### ($\Longleftarrow$) ML-random ⇒ 1-random: a test from $K$

This is the exercise, read backwards. Let $X$ be 1-nonrandom: for every $i$ there is $n\_i$ with $K(X \upharpoonright n\_i) \le n\_i - i$, so $X \upharpoonright n\_i \in L\_i$ and $X \in \widetilde L\_i$. As $i$ is arbitrary, $X$ lies in **every** layer of the test $(\widetilde L\_i)$ and is ML-nonrandom.

* **Ingredients:** upper-semicomputability of $K$ (2.23) for effectivity, Kraft on $\mathrm{dom}(\widetilde U)$ (2.25) for the measure. The shortest codes $\tau\_\sigma$ are only used *inside the proof*; the test itself is defined from $K$ alone.

### ($\Longrightarrow$) 1-random ⇒ ML-random: an i.c.m. from a test

Let $X$ be ML-nonrandom, captured by a test: $X \in \widetilde L\_i$ for all $i$, with $\widetilde L\_i$ generated by the uniformly c.e. word sets $L\_i$.

1. **Normalize the test.** Take each $L\_i$ **prefix-free** (an open set is a disjoint union of cylinders — Part 1 Notation — and this can be arranged effectively) and the $L\_i$ **pairwise disjoint as sets of words**: a word already enumerated into another layer is replaced by its two one-bit children, which leaves the open set unchanged. "Already" means earlier in the dovetailed enumeration of *all* layers, not a smaller index (membership in $L\_j$ is only c.e.), and the split is iterated if a child is taken too; it stops because only finitely many words have appeared at any stage. Disjointness is what makes the next definition single-valued.
2. **Build an information content measure.**

   $$F(\sigma) := l(\sigma) - i \qquad \text{for } \sigma \in L_{i^2},\ i \ge 2 .$$

   * $\mathbb{N}$-valued: $\sigma \in L\_{i^2}$ has $2^{-l(\sigma)} \le \lambda(\widetilde L\_{i^2}) \le 2^{-i^2}$, so $l(\sigma) \ge i^2 \ge i$.
   * (20): $(L\_{i^2})\_{i \ge 2}$ is uniformly c.e., so the graph — a fortiori the epigraph — of $F$ is c.e.
   * (19): prefix-freeness turns the layer's word-mass into its measure,

     $$\sum_{\sigma \in \mathrm{dom}(F)} 2^{-F(\sigma)} = \sum_{i \ge 2} 2^{\,i} \underbrace{\sum_{\sigma \in L_{i^2}} 2^{-l(\sigma)}}_{= \lambda(\widetilde L_{i^2}) \le 2^{-i^2}} \;\le\; \sum_{i \ge 2} 2^{\,i - i^2} = \tfrac14 + \tfrac1{64} + \tfrac1{4096} + \cdots < 1 .$$

3. **Transfer to $K$.** $K$ is the smallest i.c.m. (Thm. 3.6, form (M) in Part 3), so there is $c$ with

   $$K(\sigma) \le F(\sigma) + c \qquad \text{for all } \sigma \in \mathrm{dom}(F). \tag{24}$$

   ⚠️ The notes cite this as "Corollary 3.6.1", which is not stated anywhere in the notes; it is the minimality form of Thm. 3.6.
4. **Conclude.** Fix $i \ge 2$. $X \in \widetilde L\_{i^2}$ gives a prefix $X \upharpoonright n \in L\_{i^2}$, and (24) yields

   $$K(X \upharpoonright n) \le F(X \upharpoonright n) + c = n - i + c .$$

   The deficit $K(X \upharpoonright n) - n \le c - i$ is unbounded below, so $X$ is 1-nonrandom. $\square$

**Why the details are the way they are.**

* **Why thin to $i^2$.** Using *every* layer, $F = l - i$ on $L\_i$ has only the bound $2^{i} \lambda(\widetilde L\_i) \le 1$ per layer, which does not sum (for a Schnorr test the cost really is $\infty$ — Part 3). Using only layers $i^2$ while claiming $i$ bits costs $2^{i - i^2}$, which is summable. Any strictly increasing $g$ with $\sum\_{i \ge 2} 2^{i - g(i)} \le 1$ works, e.g. $g(i) = 2i$; the notes take $g(i) = i^2$.
* **Why $i \ge 2$.** The terms $i = 0, 1$ would each contribute $2^{0} = 1$; dropping them makes the sum $< 1$ with **no normalizing constant** (Part 3's version kept the first terms and needed a shift).
* **Why pairwise disjoint.** Only so that $F$ is a function. Alternative without normalizing: give a word lying in several layers its *smallest* value; by $\max \le \sum$ (Ex. 3.4) the Kraft sum is still $\le \sum\_{i \ge 2} 2^{i - i^2}$.
* **Where the test's bound is used.** Only in (19) — and, trivially, for $\mathbb{N}$-valuedness: $\lambda(\widetilde L\_{i^2}) \le 2^{-i^2}$. The test's effectivity gives (20).
* **Where minimality is used.** Exactly once, in (24): the compression that $F$ *declares* for the prefixes of $X$ becomes compression that $K$ *achieves*. This is the whole point of Part 3.

## The two directions side by side

| | ($\Longleftarrow$) ML-random ⇒ 1-random | ($\Longrightarrow$) 1-random ⇒ ML-random |
| :-- | :-- | :-- |
| contrapositive proved | 1-nonrandom ⇒ ML-nonrandom | ML-nonrandom ⇒ 1-nonrandom |
| given | $K$ (via $\widetilde U$) | an ML test $(\widetilde L\_i)$ capturing $X$ |
| object built | the ML test $\widetilde L\_i = \lbrace X : \exists n\ K(X \upharpoonright n) \le n - i\rbrace$ | the i.c.m. $F = l - i$ on $L\_{i^2}$ |
| effectivity from | $K$ upper-semicomputable (2.23) | the test uniformly c.e. |
| mass bookkeeping | $\sum\_{\sigma \in L\_i} 2^{-l(\sigma)} \le 2^{-i}\lambda(\mathrm{dom}\,\widetilde U) \le 2^{-i}$ | $\sum\_i 2^{i}\lambda(\widetilde L\_{i^2}) \le \sum\_{i \ge 2} 2^{i-i^2} < 1$ |
| the key inequality | Kraft on programs (2.25) | minimality of $K$ (3.6 / (M)) |
| direction of the dictionary | compression ⇒ small measure | small measure ⇒ compression |

## Consequences and outlook

* **One test to rule them all.** By 4.1, $\bigcap\_i \widetilde L\_i$ = all 1-nonrandom = all ML-nonrandom sequences: the compression test captures *every* sequence captured by *any* ML test. Such a test is called **universal**; the notes return to this in Universal Randomness Tests.
* **Randomness has full measure.** $\lambda(\lbrace X : X \text{ ML-random}\rbrace) = \lambda(\lbrace X : X \text{ 1-random}\rbrace) = 1$.
* **Two viewpoints, one notion.** From now on the notes switch freely: measure-theoretic arguments (tests, null sets) when randomness is to be *refuted*, compression arguments ($K(X \upharpoonright n) \ge n - c$) when it is to be *used*.
* **What is still open.** The third intuition — predictability via martingales — and natural *examples* of random sequences (Chaitin's $\Omega$, next chapters).

## One-glance summary

| Result | Statement | Tool |
| :-- | :-- | :-- |
| Ex. step 1 | $\sum\_{\sigma : C\_M(\sigma) \le l(\sigma) - i} 2^{-l(\sigma)} \le 2^{-i}\lambda(\mathrm{dom}\,M) \le 2^{-i}$ for prefix-free $M$ | shortest codes are injective; Kraft 2.25 |
| Ex. step 2 | $\widetilde L\_i = \lbrace X : \exists n\ K(X \upharpoonright n) \le n - i\rbrace$ is an ML test | 2.23 for effectivity, step 1 with $M = \widetilde U$ for $\lambda \le 2^{-i}$ |
| Ex. step 3 | ML-random ⇒ $\exists c\ \forall n: K(A \upharpoonright n) \ge n - c$ | escape one (nested) layer |
| corollary | 1-nonrandom sequences $= \bigcap\_i \widetilde L\_i$, a null set; 1-random sequences exist and have measure $1$ | $\lambda \le 2^{-i}$ for all $i$ |
| 4.1 ($\Longleftarrow$) | 1-nonrandom ⇒ ML-nonrandom | lies in every $\widetilde L\_i$ |
| 4.1 ($\Longrightarrow$) | ML-nonrandom ⇒ 1-nonrandom | i.c.m. $F = l - i$ on $L\_{i^2}$, $i \ge 2$; minimality (24) |
| 4.1 | 1-random $\iff$ ML-random | both of the above |
| outlook | $(\widetilde L\_i)$ is a universal ML test | 4.1 |

**Punchline.** Compression and measure are the same currency: $i$ bits of compression are a factor $2^{-i}$ of measure, because prefix-free programs carry Kraft mass. Read one way, the words that $K$ compresses by $i$ bits fit inside an open set of measure $2^{-i}$, so "some prefix is $i$ bits compressible" is a Martin-Löf test — and every ML-random sequence is 1-random. Read the other way, a test layer of measure $2^{-i^2}$ licenses an information content measure that shaves $i$ bits off the prefixes it covers, and the minimality of $K$ (Part 3) turns that licence into actual compression — so every ML-nonrandom sequence is 1-nonrandom. Theorem 4.1 is the two readings together: **incompressibility and typicality are one notion of randomness**, and the test built from $K$ is universal.
